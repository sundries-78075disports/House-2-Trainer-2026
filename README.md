## 🔥 Project Overview

**This tool** is a comprehensive trainer for **House 2**. This trainer provides optional assistance for surviving House 2's changing house, managing its time loop, experimenting with items, and overcoming dangerous action sequences. It is designed to support exploration and replayability without changing the game's core story structure.

**Target Audience:** Players who want a more accessible way to explore House 2, study its branching events, test item combinations, complete difficult action sequences, or pursue multiple endings without restarting as often.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use the trainer after gaining control of the current character. Invulnerability is useful when moving through dangerous rooms or learning enemy routes, while freezing the time loop allows careful exploration before making important decisions.

### Tools & Inventory

House 2 encourages experimentation with different items. Activate item preservation before testing consumables or using objects in unfamiliar situations. Keep the trainer disabled when checking whether a puzzle or ending condition has been completed normally.

### World & Environment

The house changes and reacts to player actions, so progression depends on observation, timing, choices, and repeated attempts. Freeze the clock while searching for clues, examining interactive objects, or comparing alternate routes. Save regularly because the game can contain run-ending situations.

### Combat & Weapons

House 2 includes action encounters and boss fights, but combat is only one part of the experience. Use invulnerability to practice enemy patterns and unlimited action resources to reduce resource pressure. Disable combat assistance when you want the intended challenge.
